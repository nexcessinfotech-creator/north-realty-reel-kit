# North Realty Reel Kit

`nr_edit.py` turns a raw clip from Umesh Patel (North Realty NT) into a finished 1080x1920 Instagram reel. It is used by the "North Realty Reels" Claude project.

- No secrets live here. The only network access is the Montserrat font from google/fonts and `pip install faster-whisper`.
- Always run a pinned commit: `git checkout <sha>`. Never run the tip of `main` unseen.
